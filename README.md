## 🎓 Теоретическое введение

### Что такое SVM (Support Vector Machine)?

**SVM (Метод опорных векторов)** — это алгоритм машинного обучения с учителем, используемый для задач классификации и регрессии. Основная идея: найти гиперплоскость, которая максимально хорошо разделяет классы в многомерном пространстве признаков.

#### Ключевые концепции:

1. **Гиперплоскость** — граница принятия решения, разделяющая классы
2. **Опорные векторы** — точки данных, находящиеся ближе всего к гиперплоскости и влияющие на её положение
3. **Максимальная граница (Margin)** — расстояние между гиперплоскостью и ближайшими точками каждого класса
4. **Ядро (Kernel)** — функция для преобразования данных в более высокую размерность

```
Линейно разделимые данные:

    ●  ●  ●     |      ■  ■  ■
       ●  ●     |   ■  ■  ■
    ●     ●     |      ■  ■
                |
         Гиперплоскость
```

### Типы ядер (Kernels)

1. **Linear (Линейное)** — для линейно разделимых данных
   ```
   K(x, y) = x^T · y
   ```

2. **RBF (Radial Basis Function)** — для нелинейных данных (самое популярное)
   ```
   K(x, y) = exp(-γ ||x - y||²)
   ```

3. **Polynomial (Полиномиальное)** — для данных с полиномиальной зависимостью
   ```
   K(x, y) = (γ x^T · y + r)^d
   ```

### Гиперпараметры SVM

- **C (Параметр регуляризации)**: контролирует баланс между максимизацией отступа и минимизацией ошибок классификации
  - Малые C → больший отступ, больше ошибок (недообучение)
  - Большие C → меньший отступ, меньше ошибок (переобучение)

- **gamma (γ)**: определяет, насколько далеко влияет один обучающий пример
  - Малые γ → далекое влияние (плавная граница)
  - Большие γ → близкое влияние (сложная граница)

### Процесс работы SVM

```
1. Загрузка данных
   ↓
2. Извлечение признаков (feature extraction)
   ↓
3. Нормализация признаков (StandardScaler)
   ↓
4. Снижение размерности (PCA)
   ↓
5. Обучение модели SVM
   ↓
6. Подбор гиперпараметров (GridSearchCV)
   ↓
7. Оценка качества модели
   ↓
8. Предсказание на новых данных
```

### Преимущества SVM

✅ Эффективен в высокоразмерных пространствах
✅ Работает даже когда размерность > количество образцов
✅ Использует подмножество обучающих данных (опорные векторы) → экономия памяти
✅ Универсальность благодаря различным ядрам
✅ Хорошая обобщающая способность

### Недостатки SVM

❌ Требует подбора гиперпараметров
❌ Может быть медленным на больших датасетах
❌ Не предоставляет напрямую оценки вероятностей (требуется дополнительная кросс-валидация)
❌ Чувствителен к шуму в данных

## 🤔 Почему SVM для изображений?

### Сравнение: SVM vs K-NN для изображений

| Критерий | SVM | K-NN |
|----------|-----|------|
| **Скорость обучения** | Медленнее | Мгновенно (lazy learning) |
| **Скорость предсказания** | ⚡ Быстро | 🐌 Медленно (сравнивает со всеми образцами) |
| **Память в проде** | 💾 Малый размер модели | 💾💾💾 Хранит весь датасет |
| **Работа с высокой размерностью** | ✅ Эффективен | ❌ Curse of dimensionality |
| **Обобщающая способность** | ✅ Хорошая | ⚠️ Зависит от K |
| **Подходит для прода** | ✅ Да | ❌ Не рекомендуется |

### Почему SVM выбран для этого проекта?

1. **Размер датасета**: 1638 изображений — оптимально для SVM
2. **Скорость в проде**: Быстрые предсказания критичны
3. **Эффективность**: Хорошо работает с PCA-преобразованными признаками
4. **Качество**: Высокая точность на изображениях
5. **Производительность**: Меньше требований к памяти

## 📊 Метрики качества

### Основные метрики

1. **Accuracy (Точность)**
   ```
   Accuracy = (TP + TN) / (TP + TN + FP + FN)
   ```
   Доля правильных предсказаний

2. **Precision (Точность положительных)**
   ```
   Precision = TP / (TP + FP)
   ```
   Доля правильных среди предсказанных как положительные

3. **Recall (Полнота)**
   ```
   Recall = TP / (TP + FN)
   ```
   Доля найденных положительных из всех положительных

4. **F1-Score**
   ```
   F1 = 2 × (Precision × Recall) / (Precision + Recall)
   ```
   Гармоническое среднее между Precision и Recall

Где:
- TP (True Positive) — правильно предсказанные положительные
- TN (True Negative) — правильно предсказанные отрицательные
- FP (False Positive) — неправильно предсказанные как положительные
- FN (False Negative) — пропущенные положительные

### Матрица ошибок (Confusion Matrix)

```
                 Предсказанный класс
              Class 1  Class 2  Class 3
Истинный  1      45       2        3
класс     2       1      48        1
          3       2       1       47
```

- **Диагональ** — правильные предсказания
- **Вне диагонали** — ошибки

### ROC-кривая и AUC

- **ROC (Receiver Operating Characteristic)** — график зависимости TPR от FPR
- **AUC (Area Under Curve)** — площадь под ROC-кривой
  - AUC = 1.0 — идеальный классификатор
  - AUC = 0.5 — случайный классификатор
  - AUC > 0.8 — хороший классификатор

### Кривые обучения (Learning Curves)

Показывают, как точность модели меняется с увеличением размера обучающей выборки:

- **Переобучение**: большой разрыв между train и validation
- **Недообучение**: низкая точность на обеих выборках
- **Хорошая модель**: высокая точность, малый разрыв

## ❓ FAQ

### 1. Сколько времени занимает обучение?

- **Анализ данных**: 1-2 минуты
- **Предобработка и PCA**: 2-3 минуты
- **Grid Search (подбор параметров)**: 5-15 минут (зависит от параметров)
- **Оценка качества**: 1-2 минуты

**Итого**: ~10-25 минут на CPU, ~5-10 минут на GPU

### 7. Что делать, если память заканчивается?

1. Уменьшите размер изображений: `IMG_SIZE = (64, 64)`
2. Уменьшите PCA: `PCA_VARIANCE = 0.90`
3. Используйте меньше параметров в Grid Search

### 8. Как улучшить качество модели?

1. **Больше данных**: увеличьте датасет
2. **Аугментация**: поворот, отражение, масштабирование изображений
3. **Тонкая настройка**: измените параметры Grid Search
4. **Feature Engineering**: попробуйте HOG вместо flatten
5. **Ансамбль**: комбинируйте несколько моделей

### 9. Можно ли использовать модель локально?

Да! Скачайте `.pkl` файл с Google Drive и используйте:


## 🔍 Анализ: Почему SVM победила?

### 1️⃣ **Размер датасета - критический фактор**

```
Требования для эффективного обучения:

Логистическая регрессия:  ~100-1,000 образцов
SVM:                      ~500-5,000 образцов    ← Мы здесь (1,638)
Random Forest:           ~1,000-10,000 образцов
CNN (transfer learning): ~10,000-50,000 образцов
ViT (fine-tuning):       ~10,000-50,000 образцов ← Нужно в 10x больше!
ViT (с нуля):            ~1,000,000+ образцов
```

**Проблема ViT:**
- Обучен на ImageNet-21k: **14 миллионов** изображений
- Наш датасет: **1,638** изображений
- **Разница: 8,500x раз!**

### 2️⃣ **Переобучение vs Обобщение**

**SVM:**
```
CV Accuracy:   94.66%
Test Accuracy: 96.65%
Разница: +2%  ✅ Хорошая обобщающая способность!
```

**ViT:**
```
Train Accuracy: 90.31%
Val Accuracy:   62.04%
Разница: +28%  ❌ Сильное переобучение!
```

ViT **заучивает** обучающую выборку, но плохо работает на новых данных.

### 3️⃣ **Линейная разделимость данных**

```
Результаты Grid Search SVM:

Linear kernel:  96.65%  ← ЛУЧШЕ! ⭐
RBF kernel:     ~94.00%

Вывод: Данные линейно разделимы в пространстве PCA!
```

Для линейно разделимых данных **не нужны** сложные нелинейные трансформации ViT.

### 4️⃣ **Curse of Dimensionality (обратная)**

**Соотношение параметров к данным:**

```
ViT:
  85,803,270 параметров / 1,638 образцов = 52,383 параметра на образец
  ❌ ОГРОМНЫЙ перебор! Модель переобучается!

SVM:
  804 признака / 1,310 обучающих = 0.61 признаков на образец
  ✅ Оптимальное соотношение!
```

### 5️⃣ **Эффективность PCA**

```
Исходная размерность: 49,152 (128×128×3)
После PCA:            804 (98.4% сжатие!)
Сохранено дисперсии:  95.02%

PCA убрал шум и оставил только важные признаки!
```

## 🎯 Когда использовать что?

### ✅ Используйте **классические ML (SVM, RF)**:

1. **Маленькие датасеты** (<10,000 образцов) ← **Ваш случай!**
2. **Табличные данные** или простые признаки
3. **Ограниченные ресурсы** (нет GPU)
4. **Быстрый прототип** нужен за несколько часов
5. **Интерпретируемость важна**
6. **Бюджет ограничен**

### ✅ Используйте **Deep Learning (ViT, ResNet)**:

1. **Большие датасеты** (>100,000 образцов)
2. **Сложные признаки** (текстуры, мелкие детали)
3. **Есть GPU** и вычислительные ресурсы
4. **Естественные изображения** (ImageNet-подобные)
5. **Нужна SOTA точность** любой ценой
6. **Есть время на эксперименты**

```
  ❌ Маленькие датасеты (<10K)

  ❌ Ограниченные ресурсы
```

## 🎓 Уроки для ML-практиков

### 1. "Больше параметров ≠ лучше качество"

```
85M параметров ViT → 70.45%
800K параметров SVM → 96.65%

Переобучение может убить любую модель!
```

### 2. "SOTA модели не всегда SOTA для вашей задачи"

```
ViT - state-of-the-art на ImageNet
Но проигрывает SVM на маленьких датасетах!

Выбирайте инструмент под задачу, а не задачу под инструмент!
```

### 3. "Простота - залог успеха"

```
Простые модели:
  ✅ Быстрее обучаются
  ✅ Легче отлаживать
  ✅ Меньше переобучаются
  ✅ Дешевле в эксплуатации
  ✅ Проще объяснить заказчику
```

### 4. "Premature optimization is the root of all evil" - Donald Knuth

```
Не оптимизируйте преждевременно!
Начните с простой модели:
1. Попробуйте SVM
2. Если не работает → попробуйте ансамбли
3. Если всё равно плохо → попробуйте deep learning
```

### 5. "Данные важнее алгоритма"

```
Хороший алгоритм + мало данных = плохо
Простой алгоритм + много данных = хорошо

Сначала соберите данные, потом выбирайте модель!
```
